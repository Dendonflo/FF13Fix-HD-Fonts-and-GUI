================================================================================
                    FF XIII HD FONT MOD
================================================================================

Replaces the original Final Fantasy XIII fonts with high-resolution versions,
resulting in sharper, cleaner text across all menus and UI elements.

This mod replaces FF13Fix. Do NOT install both — use this DLL instead.

--------------------------------------------------------------------------------
REQUIREMENTS
--------------------------------------------------------------------------------

  - Final Fantasy XIII (Steam)
  - No other mods required

--------------------------------------------------------------------------------
INSTALLATION
--------------------------------------------------------------------------------

  Copy the following files into:
  <game_install_folder>/white_data/prog/win/bin/

    d3d9.dll
    hash_database.txt
    hd_textures/
    FF13Fix.ini

  Overwrite if prompted.

--------------------------------------------------------------------------------
UNINSTALLATION
--------------------------------------------------------------------------------

  Option A — Remove HD fonts only:
    Delete hash_database.txt and the hd_textures/ folder.
    The included d3d9.dll still works as a standalone FF13Fix replacement.

  Option B — Full removal:
    Delete d3d9.dll, hash_database.txt, and hd_textures/.
    Restore the original d3d9.dll from FF13Fix if desired.

--------------------------------------------------------------------------------
WHAT'S INCLUDED
--------------------------------------------------------------------------------

  d3d9.dll        FF13Fix with built-in HD texture system
  hash_database   Texture identification database (do not edit)
  hd_textures/    High-resolution font textures
